### 📖 About The Project

**TKB Tools** is a web-based application designed to help students and teachers quickly extract their personal/class schedules from a general school timetable PDF file.

Instead of manually searching through a massive multi-page PDF, this tool automates the process and exports a clean, visually appealing schedule in PNG, PDF, or a shortened text format.

_(Note: This repository contains the Frontend source code hosted on GitHub Pages. The Backend is built with Python/Flask, hosted on Render, and kept in a separate private repository)._

### ✨ Features

- 🎓 **Student Mode**: Enter a class name to instantly extract the weekly schedule.
- 👨‍🏫 **Teacher Mode**: Automatically scans the PDF for all teachers and allows you to select your name to get your teaching schedule.
- 🌇 **Afternoon Schedule Support**: Customize your afternoon periods (1-6 periods) directly on the UI and merge them into the final output.
- 💾 **Multiple Export Options**: Download the result as a High-Res Image (`.png`), a Printable Document (`.pdf`), or copy the text summary.
- 🌗 **Dark/Light Mode**: Synced with system preferences and toggleable via the UI.
- 📱 **Fully Responsive**: Optimized for both desktop and mobile devices with a built-in zoomable image lightbox.

### 🛠️ Built With

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (Hosted on [GitHub Pages](https://pages.github.com/))
- **Backend** _(Private)_: Python, Flask, pdfplumber, python-docx (Hosted on [Render](https://render.com/))

### 📖 Giới thiệu dự án

**TKB Tools** là một ứng dụng web được tạo ra nhằm giúp học sinh và giáo viên trích xuất thời khóa biểu cá nhân/của lớp một cách nhanh chóng từ tệp PDF Thời khóa biểu tổng của toàn trường.

Thay vì phải dò tìm thủ công trên một tệp PDF hàng chục trang, công cụ này tự động hóa toàn bộ quá trình và xuất ra kết quả là một thời khóa biểu được thiết kế đẹp mắt, dễ nhìn dưới dạng ảnh PNG, tệp PDF hoặc văn bản rút gọn.

_(Lưu ý: Kho lưu trữ này chỉ chứa mã nguồn Frontend được lưu trữ trên GitHub Pages. Backend được xây dựng bằng Python/Flask, chạy trên Render và được bảo mật trong một repo riêng)._

### ✨ Tính năng nổi bật

- 🎓 **Chế độ Học sinh**: Chỉ cần nhập tên lớp để trích xuất ngay lập tức thời khóa biểu trong tuần.
- 👨‍🏫 **Chế độ Giáo viên**: Tự động quét toàn bộ tệp PDF để lấy danh sách giáo viên, chỉ cần chọn tên là có ngay lịch dạy.
- 🌇 **Hỗ trợ Lịch học buổi chiều**: Cho phép tùy chỉnh khung giờ học buổi chiều (từ 1 đến 6 ca) trực tiếp trên giao diện và gộp vào TKB chung.
- 💾 **Đa dạng Tùy chọn Xuất file**: Lưu kết quả dưới dạng Ảnh sắc nét (`.png`), Tệp in (`.pdf`) hoặc sao chép nhanh văn bản rút gọn.
- 🌗 **Chế độ Sáng/Tối (Dark/Light Mode)**: Tự động đồng bộ với hệ thống hoặc tự chuyển đổi thủ công.
- 📱 **Giao diện Tương thích**: Tối ưu hóa cho cả điện thoại và máy tính, tích hợp trình xem ảnh thu phóng (Lightbox).

- **Backend** _(Private)_: Python, Flask, pdfplumber, python-docx (Lưu trữ trên [Render](https://render.com/))
